# package_recipes

Annotated example recipes, real ones from the Spack repository or your own. These are
the agent's best few-shot examples. Name them by what they teach, e.g.
`cmake-with-optional-mpi-cuda.py`, `makefile-with-make-inc.py`, `autotools-autoreconf.py`.
Start each file with a comment explaining why it is a good example.
